# Code of Conduct

## The short version

Be a decent human. Disagree on ideas, not on people. That's it.

## The longer version

This project is open to everyone. Contributors are expected to:

- **Be respectful** — critique code and ideas, not people
- **Be constructive** — if something's wrong, say what and suggest a fix
- **Be welcoming** — beginners are welcome; everyone was one once
- **Be honest** — don't claim credit for others' work

The following will get you removed from the project without warning:

- Harassment, personal attacks, or discriminatory language of any kind
- Deliberate intimidation or sustained disruption
- Publishing others' private information without consent

## Scope

This applies to all project spaces — issues, PRs, discussions, and any other community communication tied to this repo.

## Reporting

If you see a violation, email the maintainer or open a private issue. All reports will be handled discreetly.

## Enforcement

Maintainers have the right and responsibility to remove, edit, or reject any contribution that doesn't align with this conduct. Repeat violations result in a permanent ban.
